Audit scope: I inspected the DV11 +1 execution paths, their older-engine dependencies, package loading, data builders, dialogue, realization, evaluation, and release checks at commit e190498. I ran 111 targeted diagnostic interactions plus lower-level invariant checks. This is a verified defect inventory, not a claim that every source line or external knowledge claim has been independently certified.

Current checks: strict typechecking and all 66 existing tests pass. AD1’s package validator also passes. These checks nevertheless permit the concrete failures listed below.

Verified data shape: AD1 contains 719,949 entity-to-entity propositions across 2,302 physical packages. Those propositions contain zero populated qualifiers, zero provenance validity intervals, zero negative propositions, and zero explicit world senses.

Current evaluation limitation: DV11 has 11 ordinary-question fixtures and zero real-user failure rows. Its reported 80% fixture result means 8 correct answers out of 10 answerable fixtures—not 80% ordinary-question capability. The current evidence cannot establish a 60–70% public-use answer rate.

Priority notation: P0 means a correctness or RC-readiness blocker; P1 means an important coverage, conversation, or reliability improvement; P2 means subsequent optimization or polish. No model files were changed, committed, or deployed.

[P0 ARCH-02] Preserve a supported typed answer unless another candidate proves the same requested proposition more completely. The current preferTypedResult function protects only selected operations and relations.
